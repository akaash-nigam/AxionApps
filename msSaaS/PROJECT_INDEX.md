## 📝 Project Naming Guide

All projects follow this structure:
```
msSaaS_[descriptive-name].[tld]
```

**Components:**
- `msSaaS_` - Prefix (lowercase!)
- `descriptive-name` - Project identifier (can use CamelCase or hyphen-case)
- `.tld` - Top-level domain (.in, .ca, .com, .pro, .ai)

**Examples:**
- ✅ `msSaaS_adcreatorpro.com`
- ✅ `msSaaS_EliteSchoolNavigator.ca`
- ✅ `msSaaS_ai-funding-tracker`
